## 明确限制

- 未把用户的四个门模型自动改成新版本；回归仅复用问题尺寸，不复制用户资产进仓库。
- 诊断不理解材质区域的美术语义，不提供自动绘图、PNG 替换或自动美化。
- 碰撞检查是选择范围内的实体盒离散采样；不覆盖未采样时刻，忽略透明图案形状，不能替代多视角视觉验收。正常结构连接可能相交。
- 非 Windows 宿主尚未完成真实验收。
