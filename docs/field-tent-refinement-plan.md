# 帐篷细化与 MCP 实战复盘设计

2026-11-14。模型细化先记录设计，再通过现有 v0.5.0 工具实施；本次不升级桥接协议或一次性增加所有建议工具。

## 模型目标

参考图的关键差异是倾斜侧墙、门口成对斜撑、帆布受拉形成的褶皱、磨损与缝线。保留原 final 作为比较基线，细化版另存 refined。使用相同相机、1200×900 和背景渲染前后对比；另补正交侧视与局部视图。

侧墙从底部 X=±54 收至檐口约 ±48，高差 47，倾角约 7.28°。屋顶和檐口继续沿用原高度，底部外展不挤压床铺与工作台。侧窗缩为两扇小窗，中部帆布完整，翼形标志移到条带上方。屋顶按浅波纹分段，配合细窄折痕与压边；前门改为梯形开口，增加独立斜撑、金属套箍、螺栓和多层卷帘。纹理增加方向性纤维、缝线、褶皱阴影、补丁和脏污，不依赖真实布料模拟。

内饰复用原构造并核对所有组件数量与几何；原后排物资架边缘超出内部支架宽度，允许整组向中间平移 3.5 模型单位，形状与物品完整保留。原版工程不覆盖。新版本生成官方 bbmodel、Bedrock JSON、PNG 与对比展示页。没有 Computer Use、任意宿主代码执行或工作目录外读写。

## 官方 API 调研与现有边界

- [Cube 源码](https://github.com/JannisX11/blockbench/blob/v5.2.2/js/outliner/types/cube.js)：现有项目已通过 Cube 构造、extend、setUVMode、applyTexture 接入。官方存在几何编辑能力，当前白名单只暴露 create_cubes/reparent_cubes/set_cube_uv；更新 from/to/origin/rotation 并未成为 MCP 工具。
- [Texture 源码](https://github.com/JannisX11/blockbench/blob/v5.2.2/js/texturing/textures.js)：fromDataURL 把资源设为内置并触发加载；updateSource 更新源、加载并更新材质。不能仅调用后立即视为成功，需复用已有异步解码、期限和活动工程检查。
- [Undo 官方文档](https://www.blockbench.net/wiki/docs/undo/)：元素编辑用 elements，图像修改需 textures 与 bitmap；新工具继续使用已有 edit 事务与失败回滚。纹理解码必须在同步 Undo 事务前完成。
- 现有工作目录检查、会话工程所有权、批次上限、请求截止时间和未知结果不重试规则继续有效。

## 实施顺序

1. 完成模型及材质配方，schema 与 UV 范围预检，比较内饰数据。
2. 通过真实 MCP 创建新版本、保存、导出，分页查询核对。
3. 同机位渲染，观察前后差异与穿插；修正后再次验证。
4. 实战复盘按可量化痛点排序，提出工具输入、事务边界和验收要求；建议与已实现功能分开标明。
5. 更新 README、架构入口、验证记录，提交本次资产细化与调研文档。
